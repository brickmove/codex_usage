## 产品体验打磨

在 [v0.3.3 初始基线](https://github.com/brickmove/codex_usage/releases/tag/v0.3.3) 上改善信息层级、可信数据状态和设置体验。

## 改进

- 下拉面板分为“概览 / 分析 / 重置动态”。概览集中显示账户、额度与四项统计，其他额度窗口和来源时间可展开查看，异常提示始终可见。
- 新增 Token 构成：新增输入、输出、缓存写入、缓存命中四类数值和份额，复用 CC Switch 同一统计快照，不增加计价或聚合 SQL。份额包含输出，与输入缓存命中率的分母不同。
- 设置分为“菜单栏 / 数据与刷新 / 重置动态”，保留实时预览、自选指标和排序；跨分类保留草稿，取消撤销，保存后生效。
- 修复过期额度的进度、辅助功能、Credits 估值和重置详情仍显示旧值的问题；有效额度的辅助功能保留绝对重置日期。已覆盖的历史统计不再因同步较早而显示告警色。
- 自定义日期倒置时就地提示并禁用应用/保存，错误不会污染已应用统计。面板根据所在屏幕可用高度限高，正文可滚动。
- 原有菜单栏指标、顺序和默认项保持，账户识别、唤醒恢复、跨天更新与动态未读规则保持。

## 安装

下载 `Codex-Usage-0.4.0-arm64.pkg` 安装到 `/Applications/Codex Usage.app`；更新前退出旧版。已有设置保留。需要 Apple Silicon、macOS 14+、已安装并登录的 Codex CLI；用量统计需要 CC Switch 提供数据。

```bash
shasum -a 256 -c Codex-Usage-0.4.0-arm64.pkg.sha256
```

应用采用 ad-hoc 签名，安装包尚无 Developer ID Installer 签名和公证，跨机器分发可能受到 Gatekeeper 限制；暂未提供 Intel 安装包或自动更新。
