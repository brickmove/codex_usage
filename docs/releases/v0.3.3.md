# v0.3.3 — 初始基线版本

Codex Usage 首个公开发布版本，保留产品打磨前的功能基线。后续产品打磨归入 0.4.0。

## 功能

- 菜单栏显示 Codex 额度、Credits 和重置时间，支持自选指标及排序。
- 复用 Codex CLI 已有登录状态，显示当前账户和套餐，无需在应用内登录。
- 只读 CC Switch 数据库，展示已存费用、Token 用量、请求数和缓存命中率，支持当天及自定义范围，不重新计价。
- 集成 AIHOT 重置动态，提供独立标签页和可选未读图标提示。
- 支持自动刷新、跨天更新和唤醒后的自动恢复。

## 下载与安装

适用于 Apple Silicon（arm64），macOS 14 或更高版本。下载 `Codex-Usage-0.3.3-arm64.pkg`，安装到“应用程序”后启动；应用常驻菜单栏。需要已安装并登录 Codex CLI，统计功能需要 CC Switch 提供数据。

应用使用本地 ad-hoc 签名，安装包尚未使用 Developer ID Installer 签名或公证，跨机器安装可能受到 Gatekeeper 限制。目前未提供 Intel 安装包或自动更新。

将校验文件与安装包放在同一目录后执行：

```bash
shasum -a 256 -c Codex-Usage-0.3.3-arm64.pkg.sha256
```
