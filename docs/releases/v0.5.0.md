## 自定义图标与主题

菜单栏图标、面板配色与指标顺序现在都可按自己的习惯设置。

## 新增

- 菜单栏支持默认、仪表、终端、闪电、星光、图表样式，并可导入 PNG、JPEG、TIFF、HEIC/HEIF、PDF、ICNS。提供 16 / 18 / 20 pt 三档尺寸，等比适配 Retina；图片转存为本机副本，不依赖原文件位置。
- 自定义图标默认保留原色，也可将透明底单色图设为自动适配菜单栏明暗。导入失败保留原设置；未读动态和统计异常的提示图标继续优先显示，状态恢复后显示所选图标。
- 新增青碧、海洋、森林、鸢尾、暖沙、石墨六套主题；明暗可独立选择跟随系统、浅色或深色。主题覆盖概览、分析、重置动态和设置的背景、卡片、文字与强调色。
- 已选菜单栏指标支持通过左侧手柄拖动排序，预览同步变化；保留上下箭头，方便精确调整。
- 外观与图标采用设置草稿：跨分类保留，保存后应用，取消或关闭撤销。提供分别恢复默认图标、默认外观的操作。
- 保留已有账户、数据路径、范围、刷新间隔、指标选择与顺序。兼容旧版及未知主题设置，不改变统计费用口径。

## 安装

下载 `Codex-Usage-0.5.0-arm64.pkg`，退出旧版后安装到 `/Applications/Codex Usage.app`。需要 Apple Silicon、macOS 14+；额度使用已登录的 Codex CLI，统计需要 CC Switch。

```bash
shasum -a 256 -c Codex-Usage-0.5.0-arm64.pkg.sha256
```

本版应用采用 ad-hoc 签名，安装包尚未完成 Developer ID Installer 签名和 Apple 公证；暂未提供 Intel 包或自动更新。

## 验证与边界

- 118 项自动化测试：旧偏好迁移、未知值兼容、图标持久化、常见图片格式与尺寸、等比留白、PDF 首页、坏文件及尺寸限制、提示优先级、跨多行排序及现有回归。
- 六套主题的浅深色主文字、次要文字和强调色在背景、卡片上均通过 4.5:1 对比度检查。
- 图标导入仅在本机处理，发布包不包含用户自定义图片、偏好、数据库或凭据。SVG 需要先导出为 PNG 或 PDF；PDF 取首页，其他多帧位图取首帧。
- 未实测旧版 macOS、Intel、VoiceOver 连续朗读或不同显示缩放与外接屏组合。

详细操作见 [使用指南](https://github.com/brickmove/codex_usage/blob/main/docs/user-guide.md)，截图与验证见 [验证记录](https://github.com/brickmove/codex_usage/blob/main/docs/verification.md)。
