# 可信数据在文字、图形与辅助功能中的一致呈现

问题：隐藏过期的大号数字并不等于隐藏旧数据。进度条、辅助功能标签、估值和次级明细仍可能传达“有效”的旧结果。多个视图分别判断时间还会让历史有效数据产生虚假告警。

模式：将有效性与展示值集中为纯数据对象，视图只消费结果。`RateWindowPresentation` 同时决定数字、已用描述、可选进度与 AX 摘要；`AccountQuotaPresentation` 将余额、估值、重置总数和到期一起遮蔽。窗口本身到期可局部失效，账户快照失效则作用于全部窗口和账户级数据。

```swift
let state = RateWindowPresentation(window: window, now: now, quotaIsStale: stale)
// progress 为 nil 时只画中性背景；不可另外使用 window 的旧数值生成 AX。
if let progress = state.progress { /* 绘制有效比例 */ }
```

使用时机：额度、余额、设备状态或同步统计同时具有数字、图形、辅助技术与派生明细时。用受控时钟测试边界相等、局部到期、整体失效和恢复；最后必须检查真实界面，单元测试不能证明控件消费了正确字段。

注意：来源同步状态使用业务范围判定；已覆盖历史范围不因当前同步时间较旧而失效。加载、真实零值、未知、失败与有警告的历史快照应分别表达。显示份额还应注明分母，不能将输入缓存命中率混作全部 Token 构成比例。
