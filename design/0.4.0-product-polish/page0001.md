# page0001 菜单栏面板

概览：账户 → 首选额度与 Credits/可用重置 → 范围与四指标。其他额度窗口显示数量并可展开；来源时间细节折叠，异常告警与本机记录边界始终可见。

分析：范围 → 来源/错误状态 → 总 Token → 四类构成条与各类数值/份额，明确分母包括输出，和输入缓存命中率区分；下方提供可折叠来源时间。不将本机历史归属于当前账户。

重置动态：保持现有来源、状态、北京时间、外链和已读逻辑。页头刷新按页面选择已有额度/统计或新闻操作。

自定义范围输入保留草稿；倒置提示且禁用应用；未应用时显示已应用的起止时间。页头页尾固定，正文滚动；单个次级窗口过期只遮蔽该窗口。图形不可另行暴露旧 AX 值。
