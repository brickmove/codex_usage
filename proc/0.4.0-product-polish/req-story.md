# 0.4.0 产品故事

作为已使用 Codex 与 CC Switch 的 macOS 用户，我希望扫一眼菜单栏就知道额度，打开面板即可分辨最新数据、等待同步和过期状态，按需查看 Token 构成，且能轻松设置显示内容。

1. 日常查看：保留已选图标及数值，点击进入概览，看到账户、额度和指定时段的四项统计。
2. 深入理解：切到分析，看到本机 Codex 记录的新增输入、输出、缓存写入、缓存命中；不会将其误认为当前账户的历史账单。
3. 设置偏好：按菜单栏、数据与刷新、重置动态分类设置；预览随草稿变化，取消撤销，保存生效。
4. 异常处理：过期额度的文字、图形及辅助功能均待更新；未同步数据用 —，错误提供重试入口；错误日期就地解释。
5. 获取软件：GitHub 有可下载的基线安装包、校验文件及真实限制说明，新版本可独立识别。

成功标准由 [需求规格](req-specification.md) 与 [验收用例](test-case.md) 定义。
